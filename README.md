# 🌄 The North Himalayas

**Live Website:** [thenorthhimalayas.com](https://www.thenorthhimalayas.com)  
**Tech Stack:** Next.js, Tailwind CSS, TypeScript, Vercel

---

## 🧭 Overview

**The North Himalayas** is a modern travel and adventure website showcasing curated tours, treks, and spiritual journeys across the Indian Himalayas.  
Built with performance and scalability in mind, it offers a visually rich and seamless experience for visitors — from exploring destinations to planning customized trips.

---

## ✨ Features

- 🏔️ **Dynamic Tour Packages** — Fully dynamic data-driven pages using Next.js and Tailwind CSS  
- 🗺️ **Interactive UI** — Modern gradient-based design with hover animations  
- ⚡ **Optimized Performance** — Deployed on Vercel with edge caching and lazy loading  
- 📱 **Responsive Design** — Works flawlessly across mobile, tablet, and desktop  
- 🔍 **SEO Ready** — Optimized meta tags, Open Graph, and structured data  
- 🧩 **Scalable Structure** — Built for easy addition of new destinations and experiences

## 🧱 Folder Structure
```bash
the-north-himalayas/
├── app/ # Next.js App Router pages
├── components/ # Reusable UI components
├── data/ # Tour data (Haridwar, Rishikesh, Manali, etc.)
├── public/ # Images and static assets
├── styles/ # Global styles and Tailwind config
├── package.json
├── next.config.js
└── README.md
```
