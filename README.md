## 🧭 Overview

**The North Himalayas** is a high-performance travel website built to inspire and convert. It features curated tour packages, trek listings, and spiritual journey experiences across India's most breathtaking mountain destinations — from Haridwar and Rishikesh to Manali and beyond.

Built with a focus on **SEO, speed, and seamless UX** to drive real visitor engagement and lead generation for the brand.

## ⚙️ Getting Started

```bash
# 1. Clone the repo
git clone https://github.com/Abhishek-jaswal/the-north-himalayas.git
cd the-north-himalayas

# 2. Install dependencies
npm install

# 3. Start the dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

> 🚀 Every push to `main` auto-deploys to production via Vercel.
